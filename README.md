# Wispiva

A wisp is a spark of an idea. Wispiva gives ideas a world where they can take shape, live, and evolve.

The current prototype is a work in progress. To run it locally with Node.js 24:

```sh
npm ci --prefix prototypes
node prototypes/server.mjs
```

Open `http://127.0.0.1:5175/`. Model configuration and the creation flow are described in the [prototype guide](prototypes/README.md). For project goals and current capabilities, see the [documentation index](docs/README.md).
