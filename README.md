# Wispiva

Wispiva 是一个探索生成式平行世界的项目。你可以创建人物与世界，进入其中探索地点、与居民交流，并观察事件、关系与记忆如何随时间发展。

通过改变条件、创建时间线分叉，可以从同一段过去出发，观察和比较不同的未来。

项目目前处于开发阶段，目标是让世界持续存在，让行动留下后果，让不同的可能性可以被探索。

仓库：https://github.com/kikoiio/Wispiva

## 从 Possibility 更名

产品名称为 **Wispiva**，npm 根项目名称为 `wispiva`，内部工作区包统一使用 `@wispiva/*`。

为避免更名造成登录失效、草稿丢失或已有部署断连，以下兼容标识暂时保留：

- 浏览器存储、IndexedDB、事件与 DOM 标识中的 `possibility` 前缀。
- `X-Possibility-Guest` 请求头，以及访客哈希和幂等键命名空间。
- Cloudflare Worker / D1 资源名称及临时资源清理规则；本次更名不迁移云端资源。

`mode=possibility` 表示“另一种可能”这一产品模式，不是品牌名称，保持不变。历史验收记录保留原始名称与证据链接。
