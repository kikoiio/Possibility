# s01｜P4 世界优先 UI 旅程验收 Spec

## 背景

S01 P0–P3 已分别完成兼容与权限、世界状态底座、在场体验以及 Fork/Compare 的阶段验收。P4 的世界优先 UI 已有原型；固定 API 旅程和登录态浏览器的“创建→构造→条件分叉→对照→返回”切片已有证据。当前缺口是：尚未在登录态浏览器中验证真实世界运行推进与普通居民对话组成的完整旅程；时间线快速切换和请求断流时的页面状态隔离也尚未人工验证。

## 目标

- G1：验证用户能从世界优先入口进入已创建的世界，观察世界随运行推进而变化，并能辨认实际状态与变化证据。
- G2：验证普通居民对话能在具体世界与时间线上完成；结果呈现及后续世界状态符合当前系统可证明的行为，不把对话本身夸大成必然改变世界。
- G3：验证在登录态完整旅程中，用户可从运行/对话回到观察，再进入 Fork/Compare 已有路径，并返回正确的时间线继续使用。
- G4：验证快速切换时间线及请求断流/迟到响应时，页面、订阅和异步结果始终归属当前所选时间线。
- G5：以可复核的自动化与浏览器证据判定 P4 出口；未验证或无法证明的行为保留为未通过/未知。

## 功能需求

- F1｜世界入口与当前时间线：登录用户进入世界后，界面清楚呈现当前世界、所选时间线及其运行状态；进入、返回或刷新后，用户仍能辨认自己所在的世界和时间线。
- F2｜运行推进与可观察变化：用户可从世界界面启动一次实际运行推进。运行完成后，界面显示更新后的模拟时间及可观察的世界状态或事件；若本次推进没有产生可展示变化，界面也明确显示推进结果，不伪造事件或状态变化。
- F3｜普通居民对话：用户能从当前世界/时间线进入普通居民对话，并完成一轮正常的用户消息与居民回复。对话使用所选时间线对应的居民与世界上下文；失败或中断时，界面能区分未完成回复与已完成历史。
- F4｜对话与世界结果边界：对话完成后，用户可返回当前世界并继续观察或操作。只有存在可追溯世界记录时，界面才将变化显示为世界结果；不得仅凭生成的对话文本声称世界已改变或居民已采取行动。
- F5｜Fork/Compare 路径衔接：P4 主旅程可以从观察中的世界进入已有的条件 Fork 与 Compare 流程，返回时落在用户指定的时间线上，并能继续观察或对话；本阶段不重新定义 Fork/Compare 的业务规则。
- F6｜切换时间线隔离：切换世界或时间线后，页面中事件、发言、时钟、居民详情、对话及状态面板都对应新选择；旧订阅、迟到响应或先前请求结果不能覆盖当前线的内容。
- F7｜访问模式边界：匿名用户仍只能浏览允许公开的只读首页内容，不能启动运行、发送普通对话或执行其他写入动作；登录用户的能力依其当前模式和世界权限呈现。

## 非功能需求

- N1｜可重复性：自动化旅程使用固定世界、合成账号、固定时钟和可控模型替身；同一输入可重复得到可比对的运行与对话结果。
- N2｜时间线一致性：所有页面读取、运行和对话请求都绑定明确的世界与时间线；页面仅接纳属于当前选择且版本不倒退的结果。
- N3｜失败可恢复：运行或对话发生拒绝、超时、断流或取消时，界面如实呈现状态；未完成的居民回复不能作为完整历史展示，用户能返回世界或按提示恢复。
- N4｜权限与只读：验证使用合成用户与本地隔离数据；匿名入口只读，跨用户或无权时间线请求被拒绝且无写入副作用。
- N5｜环境隔离：阶段验收不访问生产/远端数据库、不部署、不将测试数据写入默认本地数据库；临时服务与数据可清理。
- N6｜证据可复核：每项验收结果记录所用世界/时间线、命令或浏览器步骤、可观察结果和失败项；不得以构建通过或测试总数替代用户旅程证据。

## 不做的事

- 不重做世界优先 UI 的整体信息架构或视觉设计；只修复完成 P4 主旅程所需且验收中实际暴露的问题。
- 不重开已通过的 P0–P3 阶段，也不改变 Fork、Compare、权限、版本化提交或世界模拟规则。
- 不要求居民对话必然改变模拟状态、产生特定事件、记忆或关系结果；只验证可观察且有来源的结果。
- 不以本阶段证明模型回复真实、符合某种文风，或证明模拟结果可以预测现实。
- 不要求生产数据库、部署环境、远端服务或真实模型作为通过条件。
- 不新增独立产品子系统、数据迁移或管理后台；若验收发现缺陷，仅做完成本阶段旅程所需的最小调整。
- 不把已有匿名只读首页或 P3 Fork/Compare 细节重新扩展成独立改版项目；仅保留与本阶段旅程衔接有关的回归检查。

## 验收标准

- AC1｜世界与时间线定位：使用合成登录账号创建或打开验收世界，进入、刷新并返回后，页面始终显示所选世界和时间线；不存在的或无权访问的时间线被明确拒绝。（F1、N2、N4）
- AC2｜实际运行推进：在登录态世界页启动产品运行入口并完成至少一次真实模拟推进；观察到模拟时间按规则前进，并能查看本次运行后的状态/事件证据。若没有新事件，页面如实显示无新事件，不补造变化。（F2；N1、N3、N6）
- AC3｜普通居民对话：在当前世界与时间线中完成一轮普通居民聊天；居民回复进入完成历史。另覆盖一次断流或失败，确认半截回复不作为完整居民回复呈现，既有用户输入及重试/恢复提示符合实际持久化状态。（F3；N1–N3）
- AC4｜对话结果边界：完成聊天后返回世界，核对可见状态、事件或记忆的来源；没有可追溯记录时，不出现“世界已改变”或“居民已行动”的断言。（F4；N2、N6）
- AC5｜主旅程衔接：从观察中的世界创建带明确条件的 Fork，进入 Compare，返回所选时间线后继续观察或聊天；当前世界、时间线和页面状态始终一致。P3 已覆盖的 Fork/Compare 证据展示不在此重复做完整验收，只检查本旅程所需衔接。（F5）
- AC6｜时间线切换与迟到结果：在登录态快速切换两条时间线，并让旧线请求或订阅结果迟到；切换后页面只显示新线内容，旧结果不能倒退版本或覆盖新线。另检查断流后切换时间线，旧请求不能污染新线。（F6；N2–N3）
- AC7｜匿名只读边界：匿名访问首页可查看允许公开的内容；尝试运行、发起普通对话或写入均被拒绝，数据库中的版本、命令、事实及投影不变。（F7；N4–N5）
- AC8｜P4 出口记录：记录 AC1–AC7 的实际命令、浏览器步骤、结果与环境；自动化结果、登录态人工观察和未验证项分别说明。只有 AC1–AC7 全部通过且证据可复核，才标记 S01 P4 出口通过；失败或未知项继续保留为未通过/未知。（N5–N6）
