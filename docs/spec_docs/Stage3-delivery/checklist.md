## 实现行为

- [ ] 在同一世界切换 2D/3D 后，`worldId`、`timelineId`、身份、历史与世界时间保持一致（验证：用同一测试世界切换两种表现，比较切换前后页面上下文和时间线事件；确认没有新建世界或意外推进时间）。
- [ ] 用户能在分屏两侧分别选择世界、时间线与 2D/3D 表现（验证：操作左右控制项，观察 URL 与各 pane 的目标；确认单侧选择不改变另一侧）。
- [ ] 同世界双时间线分屏支持 2D/2D、3D/3D、2D/3D、3D/2D（验证：逐种选择组合，确认两侧显示对应时间线与目标表现）。
- [ ] 当前身份有权访问的两个不同世界可以分屏，且支持上述四种表现组合（验证：使用有权访问的测试世界组合逐项切换，确认左右 `worldId`、时间线和表现匹配选择）。
- [ ] 分屏两侧分别显示各自实际加载的时间与访问能力（验证：使用时间和权限不同的左右测试上下文，比较两侧标签及可用操作；权限不从 URL 推断）。
- [ ] 一侧拒绝访问、超时或加载失败时，另一侧仍能显示并交互；重试只重新加载失败侧（验证：分别注入左侧和右侧失败，操作可用侧并重试失败侧，观察另一 pane 状态未被重置）。
- [ ] 同一 `worldId` 且同一表现类型时，用户可开启或关闭相机联动（验证：在同世界双 timeline 的 2D/2D 与 3D/3D 中移动或缩放一侧，比较联动开/关效果）。
- [ ] 跨世界或混合表现时，相机保持独立且联动不可启用（验证：对跨世界四种表现组合及同世界 2D/3D、3D/2D 尝试联动，确认另一侧视野不变）。
- [ ] 页面刷新和表现往返切换后，浏览器偏好按约定恢复，相机按世界、时间线和表现分别恢复（验证：设置偏好和不同目标相机，刷新并在目标间切换，确认各自恢复且没有账号同步依赖）。
- [ ] 显式 URL 表现覆盖浏览器默认偏好；存储损坏或不可用不会丢失世界上下文（验证：设置冲突的浏览器偏好和 URL 值，并模拟无效记录/存储异常，观察实际表现及错误降级）。
- [ ] 不支持目标表现或 adapter 加载失败时，当前世界上下文仍保留，并显示原因和可操作的替代方式（验证：使用不支持/失败 fixture，观察 pane 的上下文、提示和后续操作）。
