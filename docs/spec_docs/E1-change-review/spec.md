# E1：变化发现、证据追溯与离开期间回顾

## 背景与目标

### 背景

K1 已建立居民知识边界，F1 已把受支持的消息和地点环境变化写成子线事实、命令与事件，并保留来源。现有事件、历史和分叉比较入口能查看部分记录，但还缺少一条连续路径，让用户发现重要变化、展开当时的来源证据与可见知识、理解哪些是事实、可能相关的推断或未知，并在再次访问时回顾离开期间发生的变化。讨论稿要求解释依托原始记录，且不由模型事后编造原因。

### 目标

建立“发现变化 → 查看事件与证据 → 按权限理解事实、可能相关的推断和未知 → 从事件时点或检查点继续分叉比较”的连贯体验。回顾内容必须由可追溯的事件、命令、事实、状态和观察者可见知识构成；来源可定位到人物、地点、时间线和时间。分叉入口可从所选检查点预填条件，但不得把相关性呈现为已证实因果。

## 功能需求

- **F1 变化发现：** 登录用户可在主画面发现自上次查看后新增的世界变化；入口显示简短摘要，并可打开事件列表。来源明确的状态改变与约定变化按确定性规则突出显示；其他新事件仍可在完整列表中查看。
- **F2 事件与证据详情：** 事件详情展示实际保存的事件、来源命令、关联事实与当时状态；按权限展示观察者当时可见的知识。缺少来源记录或历史状态时，明确标为未知或不可重建。
- **F3 事实、推断与未知：** 界面明确区分记录支持的事实、可能相关但未证实的推断和未知；不得由模型事后生成因果解释，也不得把时间相邻当成因果。
- **F4 事件定位：** 事件可定位到相关人物、地点、所属时间线与模拟时刻；只有证据覆盖该时间点时才提供历史查看或分叉入口。
- **F5 检查点分叉：** 从可重建检查点发起 fork 时预填假设和起始时刻；用户仍须检查并确认，条件执行沿用 F1 的服务端校验与回执。
- **F6 离开期间回顾：** 回顾仅依据当前时间线中已写入且不晚于当前模拟时刻的记录；按时间顺序展示。标记已读水位按用户和时间线隔离。已有约定与未读消息保持现有权限和行为。
- **F7 首版权限范围：** 第一版限定登录世界所有者；沿用 K1 可见知识规则，私人消息正文只向获准观察者展示。访客/demo、完整历史场景回放和自动因果归因不纳入本期。
- **F8 不完整证据：** 来源不完整、事件无法关联事实或历史状态无法重建时，仍可查看原始事件，并清楚说明证据缺口；读取失败可重试，不把不完整记录包装成确定解释。

## 非功能需求

- **N1 可追溯：** 回顾中的事实、来源和状态均关联已持久化的事件、命令、事实或可重建检查点；每项可展示信息都能定位到时间线和模拟时刻。缺失关联时保留原始记录并显示证据缺口。
- **N2 知识与隐私：** 事件详情和摘要按登录世界所有者权限读取；居民可见知识沿用 K1 的证据边界。私人消息正文仅向获准观察者展示，公共事件和未授权摘要不得泄漏正文。
- **N3 时间边界：** 回顾查询只读取当前时间线、当前模拟时刻及之前的记录；跨线比较只访问用户明确选择且有权限的时间线。已读水位以用户和时间线为键，不混用不同分支进度。
- **N4 诚实表达：** 事实、可能相关的推断、未知分别呈现。推断只能说明记录之间的可能关联并显示依据，不生成未经记录支持的因果结论；历史状态不可重建时不得提供历史场景或分叉入口。
- **N5 可用性：** 回顾摘要和事件详情应支持空结果、部分证据、读取失败和重试；标记已读只推进到服务端实际返回且属于当前时间线的记录水位。
- **N6 兼容与效率：** 复用现有事件、命令、事实和检查点存储，不重复生成世界事实；分页或有界返回事件，避免回顾一次加载无界历史。既有约定与未读消息的权限和行为保持兼容。

## 不做的事

- 不生成无记录依据的事后原因，不做因果证明、贡献度计算或行为预测；可记录的候选关联仍标作推断。
- 不重建证据未覆盖的历史状态，不提供缺乏检查点依据的历史场景回放或从该时刻分叉。
- 不实现完整的逐帧或互动式历史回放；首版展示事件、关联证据、状态摘要和可用检查点。
- 不改动居民既有约定、私信投递、未读消息计数和其权限语义；E1 的离开期间变化回顾聚焦世界记录，不代替聊天收件箱。
- 不开放访客/demo 的回顾、跨账号共享回顾或居民端的完整证据浏览；首版针对登录世界所有者，并按既有权限限制正文。
- 不为补齐旧记录而生成或改写历史事实、事件、居民记忆；历史缺口只标示并允许重试读取。

## 验收标准

1. 用户打开登录世界后，可看到自上次查看水位以来的变化摘要；来源明确的状态改变和约定变化按确定规则突出显示，其他新事件仍可从完整事件列表访问。无新增记录时显示清楚的空状态。
2. 打开一项变化可查看已保存的事件、可关联的命令/事实、人物、地点、时间线和模拟时刻；关联缺失或历史状态无法重建时仍显示原始事件，并指出具体证据缺口。
3. 详情分别标明记录事实、基于记录的可能关联和未知；没有足够来源时不显示因果结论。相邻时间发生的事件不会自动被描述为因果。
4. 私人消息正文只对获准的世界所有者观察者可见；事件流、其他居民的可见知识和摘要不包含该正文。居民视角信息仅依据 K1 合格可见证据。
5. 时间线和模拟时刻过滤正确：不混入其他分支或当前模拟时刻之后的数据。已读水位按用户与时间线隔离；标记已读只确认页面实际收到的有效记录，重试或再次进入不丢失或污染其他线进度。
6. 仅当选定时点有充分证据可重建时，才提供历史状态查看和从该检查点分叉；入口预填时点及假设，用户确认后走 F1 校验和执行回执。缺少证据时解释不可用原因。
7. 证据读取失败可重试；部分或旧记录不会触发事实或记忆写入。既有约定与未读消息行为保持兼容。
