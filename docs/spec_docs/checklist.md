# 虚拟邻居（Virtual Neighbor）Checklist

> 依据 [spec.md](spec.md) 验收标准（AC1–AC12）与 [plan.md](plan.md) 集成点设计。
> 每项通过运行代码或观察行为验证，不依赖读实现。

## 实现完整性

- [ ] 世界自动运转：部署后无需人工操作，心跳间隔自动产生新条目
  （观察演示环境时间线，一个心跳周期内有新内容）——AC1
- [ ] 夜间休眠：配置休眠时段覆盖当前时间时，时间线无新增
  （对比休眠窗口前后条目数）；休眠结束后恢复新增——AC1
- [ ] 人格档案即居民：新增一份合法档案并重新部署，新居民出现在
  居民接口与时间线（访问居民接口看到新名字）——AC2
- [ ] 档案校验：提交缺关键字段的档案，载入失败且错误信息指名
  问题字段（观察报错文本）——AC2
- [ ] 记忆连续：连续运行数日后，独白/对话中引用数天前的事件
  （翻阅时间线找出至少 1 处实例）——AC3
- [ ] 反思沉淀：记忆存储中可观察到 reflection 类条目
  （查记忆表 kind=reflection 有记录）——AC3
- [ ] 世界状态完备：任意时刻每位居民有确定位置与进行中的活动
  （读世界状态快照核对两名居民）——AC4
- [ ] 相遇互动：两名居民同地时产生对话条目
  （观察时间线中出现同地点双人对话条目）——AC4
- [ ] 作息规律且多变：连续多日条目呈规律作息（清晨备料等）且
  每日内容不完全重复（对比相邻两日同时段条目）——AC5
- [ ] 世界事件影响：出现受天气/季节/背景人物影响的条目
  （翻阅时间线找出至少 1 处实例）——AC5
- [ ] 日常之谜生命周期：连续运行一周内至少一个谜团经历
  "出现→调查→揭晓"，揭晓内容与谜面线索呼应且无犯罪细节
  （按类型筛选 mystery 条目逐条核对）——AC6
- [ ] 季度谜团推进：星野旧案有阶段性推进条目
  （筛选相关条目观察阶段进展）——AC6
- [ ] 条目三要素+类型：每条目含角色、时间、地点、类型标签，
  动态/对话/独白三类齐备（页面观察）——AC7
- [ ] 口吻可辨：隐去作者名读 5 篇独白，能分辨星野与七濑，
  正确 ≥4 篇（人工盲测）——AC7
- [ ] 护栏拦截：构造含违规内容的待发布条目，不出现且留有
  拦截记录（查拦截记录表）——AC11
- [ ] 档案过护栏：含违规内容的档案载入被拒绝——AC11
- [ ] 条目下线：管理员标记某条目下线后，接口与页面均不再返回
  （下线后刷新页面与 curl 接口双重确认）——AC11

## 集成

- [ ] cognition 被模拟器驱动调用，且二期 respond 接口存在
  （编译通过 + 类型导出可引用）
- [ ] store 为唯一平台耦合点（全仓库搜索 D1 绑定类型引用，
  仅出现在 store 访问层）
- [ ] 居民接口不泄露内情：返回体中无 secrets 内容
  （调居民接口，核对响应字段；对照档案 secrets 原文搜索无命中）
- [ ] 公开路由无写操作：对公开路由尝试 POST/PUT/DELETE，
  全部 404/405（curl 逐个验证）——AC8
- [ ] 管理端点鉴权：无 token / 错 token 调用管理端点返回 401——AC11
- [ ] 接口与页面一致：同一时刻接口返回与时间线页面所见一致
  （curl 与页面双开对比）——AC8
- [ ] 配置热生效：修改运行配置（激活率/休眠窗口）后下一个 tick
  行为变化，无需改代码（对比修改前后条目产出）——AC10
- [ ] 用量可观测：管理端点返回按天的调用次数与估算成本
  （调用用量日报，核对有数据且与条目产出吻合）——AC10/N1
- [ ] 演示隔离：演示环境条目不出现于正式环境接口
  （对比两端点时间线）——AC10
- [ ] 前端仅使用公开接口：前端全部数据来自公开只读路由
  （观察网络请求面板，无任何 admin 调用）

## 端到端场景

- [ ] 场景 1 · 访客的一天：打开嵌入博客的信息流页 → 看到近期
  新条目（含作息相关的动态）→ 用筛选只看七濑 → 读到她的独白 →
  点进居民主页看人格介绍 → 全程页面无任何输入控件
  （桌面与 375px 宽各走一遍）——AC9
- [ ] 场景 2 · 一个谜团的完整周期：mystery 条目放出谜面 →
  后续出现调查/线索条目 → 揭晓条目落地，内容温暖、与谜面呼应
  （连续观察数日，按类型筛选串联阅读）——AC6
- [ ] 场景 3 · 运维一日：手动触发 tick → 新条目出现 →
  查当日用量日报 → 下线一条条目 → 页面与接口同步消失
  （按序操作并逐项确认）——AC10/AC11
- [ ] 场景 4 · 中断续跑：人为制造一次 tick 中断，下一心跳自动
  续跑，世界状态与故事进度无丢失（对比中断前后快照与时间线）——AC12
- [ ] 场景 5 · 新居民入住：编写第三份合法档案 → 重新部署 →
  新居民出现在居民接口、世界状态与时间线
  （端到端验证 G4，无需改任何代码文件）——AC2
