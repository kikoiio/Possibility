# K1：分叉设定与居民知识、时间线隔离 Spec

> 状态：整份 Spec 已获用户批准。
> 日期：2026-10-04。
> 工作线：B——世界可信性与分叉。

## 背景

Possibility 已有居民级知识筛选、事实来源校验、祖先时间线可见性和分叉快照。当前聊天与自主模拟提示词仍会把完整分叉设定直接提供给居民模型输入。代码审查确认存在信息越界风险，但尚不能据此断言居民已经发生实际泄漏。

## 目标

- 保留完整分叉设定作为构造者记录，同时只向居民提供其有权依据的事实、记忆和可见证据。
- 覆盖居民直接交谈、在场交谈、居民间对话、自主生活决策、对突发事件的反应，以及居民记忆和摘要整理。
- 保留分叉点前合法继承的共同历史；让各分叉及其后代的分叉后记忆和证据只在相应时间线可见。
- 允许居民通过本人可见的事实、亲历或他人传达获知信息；传闻继续标为传闻，不自动升级为事实。
- 对可能受旧提示词越界影响的分叉后记忆和摘要，按居民可见的原始对话、事实与行动记录重建；无法核实的派生内容从居民后续输入中排除并标记为未能重建。
- 多位居民共享模型调用时隔离各自输入；无法保证隔离时拆分调用。

## 功能需求

- **F1：分叉设定与居民上下文分离。** 完整分叉设定保留为构造者记录。居民模型输入不得直接包含完整分叉设定；只能包含该居民依据可见事实、个人经历或合法记忆能够获知的内容。
- **F2：按居民筛选知识。** 私人信息只提供给记录指定接收者的居民。世界级环境事实按现有可见范围提供。没有可见证据的信息不得因其出现在构造者记录、其他居民记忆或系统内部状态中而自动进入该居民输入。
- **F3：传播保留来源与确定性。** 居民可使用本人目击、参与的对话或有来源的记录获知内容。居民转述私人信息后，接收者只能获得该次传播实际提供的信息；传闻在传播及后续记忆中继续标为传闻，不能自动变成已证实事实。
- **F4：共同过去继承、分叉未来隔离。** 分叉点之前、来源合法且对该居民可见的共同记忆和事实可以继承。分叉点之后产生的记忆、事实和传播记录只在其所属时间线及合法后代中可见，不得进入父线、兄弟线或其他无关分支。
- **F5：重建受影响的历史记忆。** 对使用过完整分叉设定的既有分叉时间线，重建分叉点之后受影响居民的记忆与摘要，且只依据该居民可见的原始对话、事实和行动记录。无法由这些记录核实的派生内容不再提供给后续居民模型输入，并记录为未能重建；合法共同历史和主线原始记录保留。
- **F6：覆盖所有居民视角的模型输入。** 上述边界适用于普通聊天、在场交谈、居民间对话、自主模拟决策、日程与生活节拍、突发事件反应、记忆压缩与摘要，以及其他以居民身份生成输入的模型调用。面向构造者的分叉预览和面向用户的历史叙述不属于居民知识入口。
- **F7：多人调用隔离。** 一次模型调用涉及多位居民时，每位居民只接收各自获准的信息。若调用格式无法确保逐人隔离，则分别调用，不能把多人的私人知识合并成共享上下文。

**对应验收覆盖：** F1–F3 检查未授权信息不进入输入、合法传播可达且传闻不升级；F4 检查共同历史继承和父线/兄弟线/后代隔离；F5 检查旧记忆重建及证据不足时的排除；F6–F7 检查各提示路径和多人调用的输入边界。

## 非功能需求

- **N1：失败时默认不暴露。** 居民知识筛选、来源验证或上下文重建失败时，不得回退到注入完整分叉设定或未经筛选的记忆；该次居民模型调用应安全失败或使用不含争议信息的上下文，并留下可诊断结果。
- **N2：证据完整且确定性不升级。** 居民可见信息应能追溯到所属时间线中的来源记录及获知时刻。未知内容保持未知，推断不标成事实，传闻不升格为事实。
- **N3：历史重建可恢复且可重复。** 重建过程按有限批次处理，支持中断后继续；重复执行不得重复生成记录或覆盖原始对话、事实、行动证据及合法共同历史。重建结果应能区分成功、证据不足和执行失败。
- **N4：旧数据兼容。** 缺少来源、字段不完整或快照格式较旧的记录不得被推断成居民可见信息。无法验证可见性的历史内容按“未能重建”处理，并继续遵守居民提示词边界。
- **N5：运行与调用成本可控。** 居民知识隔离不应引入持续后台模型调用。必须拆分多人调用时，应沿用既有预算、重试和失败记录机制；旧记忆重建的资源需求与处理进度应可观测。
- **N6：验证范围透明。** 需要检查实际生成的模型输入，并用少量真实居民对话复核行为。提示词检查和有限对话样本提供边界证据，但不宣称能够统计证明模型在所有情况下绝不输出泄漏内容。

**确认默认值：** 历史重建失败或证据不足时，原始记录保留，但无法核实的派生记忆不进入后续居民模型输入。

## 不做的事

- 不实现 F1 中“受支持的分叉条件变成真实世界状态”的执行流程，也不把 `changedVariable`、`invariants` 或完整分叉设定描述成已经生效的规则。
- 不处理 K2 电话与空间事实一致性、K3 未设定信息与人物认知边界；两者各自另写规格。
- 不新增任意信息传播、社交网络或通信机制；仅依赖本规格认可的居民可见事实、亲历、对话和已有来源记录。
- 不改变构造者查看或保存完整分叉设定的权限，也不改变分叉创建、命名和用户界面流程。
- 不重写或删除原始对话、世界事实、事件及行动记录；历史修复范围仅包括受影响居民的派生记忆与摘要。
- 不将历史事件叙述或环境状态自动改写为可信事实；发现无法核实的内容时按“未能重建”处理。
- 不改造面向用户的章节回顾、分屏比较文案、2D/3D 渲染或模型供应商；它们不是居民知识输入入口。

**与后续阶段的边界：** K1 建立居民知识和分叉时间线的隔离基础；分叉条件真实执行和变化解释仍由 F1、E1 后续规格定义。

## 验收标准

- **AC1（F1）**：在分叉设定包含仅甲可知的秘密时，检查甲、乙的居民模型输入；两者都不含完整构造者设定，且乙的输入中没有甲的秘密。
- **AC2（F2）**：为甲记录私人事实、为所有居民记录世界级环境事实；生成输入时甲可见自己的私人事实，乙不可见，所有符合当前世界可见范围的居民均可见环境事实。
- **AC3（F3）**：甲在获准上下文中读取私人信息后，在与乙实际交流并传达的分支中，乙才可获得对话实际传达的内容；若内容标为传闻，乙及后续记录仍将其标为传闻。
- **AC4（F4）**：验证分叉前合法且对居民可见的记忆能被子线继承；分叉后仅在某一子线产生的信息不会出现在父线、兄弟线或无关分支中，并能在该子线的合法后代中按规则继承。
- **AC5（F5）**：对含越界信息的模拟记忆和摘要执行重建；可由居民可见原始证据支持的内容被重建，无法支持的内容被标为未能重建且不会进入后续提示词。重复重建不重复创建记录，也不改变原始资料及合法共同历史。
- **AC6（F6）**：分别检查普通聊天、在场交谈、居民间对话、自主决策、日程、生活节拍、突发事件反应、记忆压缩和摘要整理所生成的实际居民输入；所有路径均不包含完整分叉设定或未经授权的信息。
- **AC7（F7）**：当同一调度涉及掌握不同信息的多名居民时，逐人检查输入；输入互不包含对方的私人知识。无法按居民隔离的调用被拆分，或在发出模型请求前失败关闭。
- **AC8（N1、N4）**：制造知识来源缺失、历史快照不完整或来源验证失败；系统不回退到完整分叉设定或未经筛选的记忆，居民模型输入中不出现争议信息，并留下可诊断状态。
- **AC9（N3、N5）**：中断后继续历史重建，并重复执行一批数据；处理状态可观察、不会重复生成派生记录，且不会触发既有预算护栏之外的后台模型调用。
- **AC10（N6）**：检查代表性真实居民对话前的实际模型输入，并复核少量对话结果；记录实际覆盖的居民、时间线和调用路径，不据有限样本宣称绝对不会泄漏。

**限制说明：** AC10 验证提示词边界和有限样本中的行为，不构成对所有模型输出的数学保证。
