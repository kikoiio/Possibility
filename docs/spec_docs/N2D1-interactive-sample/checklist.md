## 使用与证据规则

- 本清单是待执行验收，不是完成报告。仅有对应证据时勾选；未执行、环境缺失、跳过或资源限制都记为未完成，不能当作通过。
- 规格/契约/CSS检查用于模块交付；浏览器完整行为与美术观察另有检查。截图辅助视觉判断，不能单独证明交互或保存成功。
- 固定数据证明可重复行为，真实公开读取证明目标身份与接口；二者分别记录。真实API不可用时继续其他独立验证，但必需真实证据仍待完成。
- 单元验证使用有限worker；构建与浏览器按主agent排程。命令仅在用户明确启动开发后执行，不额外启动seed、模型、节拍器或正式世界写入。
- 每条证据记录检查ID、通过/未通过/未完成/不适用、执行日期、工作区/提交、环境、命令或动作、实际结果及trace/截图/日志位置。失败记录修复与复验范围。
- 稳定行为是通过条件，具体测试文件和命令仅为本期执行入口；重构后可更新入口，但不能降低对应行为要求。

## 环境与执行入口

默认桌面1280×720，触屏390×844；手工样板前端5174，独立浏览器前端15174，代理已有API（默认8787）。复用服务前确认目录与提交；端口冲突时只调整本任务端口，不结束其他服务。

独立浏览器结果存于 `/tmp/native2d-playwright-results`，最终证据索引需注明保留位置；临时目录会清理，验收报告/必要证据在清理前保留到本任务文档或明确的交付附件。

仓库根目录：

```bash
npm --workspace web test -- src/native2d/__tests__ --maxWorkers=1
npm --workspace web test -- --maxWorkers=1
npm --workspace web run build
npm ls --workspace web pixi.js
```

web目录，三项目依次调度：

```bash
../node_modules/.bin/vitest list
../node_modules/.bin/playwright test --config=playwright.native2d.config.ts --list
../node_modules/.bin/playwright test --config=playwright.native2d.config.ts --project=native2d-desktop
../node_modules/.bin/playwright test --config=playwright.native2d.config.ts --project=native2d-mobile
../node_modules/.bin/playwright test --config=playwright.native2d.config.ts --project=native2d-live
```

现有3D受影响回归在web目录运行，端口先确认空闲；该配置会启动隔离API与前端，与上述浏览器任务错峰，输出单独覆盖：

```bash
PLAYWRIGHT_API_PORT=18787 PLAYWRIGHT_WEB_PORT=15173 ../node_modules/.bin/playwright test --config=playwright.config.ts --project=desktop-chromium --workers=1 --output=/tmp/native2d-3d-regression-results e2e/s03-map-entry.spec.ts e2e/s5a-navigation-world-list.spec.ts e2e/s5b-visual-finish.spec.ts
```

当前web无独立lint脚本，验收时复查脚本并如实记不适用。性能证据注明实际硬件、浏览器版本、renderer、DPR、操作区间和方法；按需渲染静置drawCount不是交互FPS，SwiftShader和真实硬件表现分开，沿用spec要求，不增加通用FPS硬门槛。
