# N2D1：原生 2D 庄园可交互样板 Spec

> 状态：四份规格文档已全部获用户批准；用户要求暂不开发，等待明确启动指令。尚未开始实现。
> 日期：2026-10-04。

## 背景

Possibility 已有世界、居民、地点、时间线与模拟能力。本期沿用这些公共能力，新增独立的原生 2D 可交互样板，探索更贴近雾影庄氛围的视觉与操作体验，并与现有体验修复工作并行推进。

样板读取真实世界的只读状态，配合固定测试数据验证表现。建筑编辑仅改变本地 2D 布局。

用户已比较三套概念方向，选择冷色悬疑风格，并要求提高人物与通路的可读性。概念图作为美术方向参考，不代表素材已拆分、动画已实现或交互已通过验证。

## 目标

- 提供一个庄园外景与一个室内，形成连贯的冷色悬疑视觉体验。
- 在对应昼夜状态下，清楚辨认居民、建筑、入口与通路。
- 支持观察者选择居民和地点、查看已知活动、跟随居民及观察室内。
- 支持建筑移动、占地和入口连通校验、撤销，并保持地点身份与室内绑定。
- 本地保留编辑结果，刷新后可恢复，也可重置。
- 通过桌面与触屏上的实际操作验证样板，为后续正式存档和双入口集成提供依据。

## 功能需求

### F1：样板与数据来源

提供独立的 2D 样板入口，支持真实雾影庄只读数据与固定测试数据，并明确显示当前数据来源。读取真实数据不创建世界、推进时间或修改世界状态。

### F2：状态查看与刷新

展示所读取状态中的世界时间、居民地点和已知活动，提供手动刷新。加载或刷新失败时显示可理解的反馈与重试入口；已有画面可以保留，但须标明尚未更新。

### F3：外景浏览

提供固定斜俯视的庄园外景，支持平移、缩放和返回全景。建筑、道路、居民与入口具有清楚的视觉层次。

### F4：居民与地点选择

选择居民后，可查看姓名、所在地点和已知活动，并开启或取消跟随；选择地点后，可查看地点信息和在场居民。被遮挡的选中对象仍应能够辨认。

视觉跟随适用于样板可呈现的空间。目标处于样板无法呈现的地点时，保留其真实地点信息，并明确提示无法继续视觉定位，不将其放到其他地点。

### F5：室内观察

支持从外景入口观察一个室内空间，并返回外景。观察室内不改变用户或居民在真实世界中的位置；建筑移动后，其室内绑定仍然有效。

### F6：居民表现与事实一致

居民位置和活动信息依据读取的数据呈现。缺少动作或移动过程的证据时，展示已知状态；视觉表现不虚构已经执行的行为。

### F7：建筑移动与校验

编辑时支持选择建筑、预览新位置，并校验边界、占地冲突及入口连通。合法位置才能应用；非法位置显示原因并保留原布局。移动后地点身份、室内绑定和居民归属保持一致。

通路校验针对本地 2D 样板布局；应用建筑移动不修改后端行动规则。

### F8：撤销

已应用的建筑移动可以按操作顺序逐步撤销，恢复对应布局与通路。撤销不回退真实世界的时间、居民状态或历史。

### F9：本地恢复与重置

建筑编辑结果在当前浏览器中保留，刷新后恢复对应样板布局，并提供重置入口。本地数据损坏或不兼容时，明确提示并允许恢复初始布局。

## 非功能需求

### N1：视觉风格与可读性

保持冷色悬疑风格、环境层次和局部暖光。居民、道路、入口、选中状态和编辑预览在对应昼夜状态下均应清楚可辨。

### N2：素材一致性与可编辑性

建筑、居民、植被和室内家具使用一致的比例、轮廓与光照规则。可移动建筑、入口和遮挡层须能够独立表现，避免将可编辑对象画死在背景中。

### N3：桌面与触屏可用性

平移、缩放、选择、室内切换、建筑移动和撤销均支持鼠标与触屏。重要操作不依赖悬停；拖动地图、点击对象和移动建筑应有明确区分。

已确认的默认验收尺寸为桌面 1280×720、手机竖屏 390×844。

### N4：状态与编辑隔离

真实世界数据保持只读。本地布局按数据来源、世界和时间线分别恢复，不混用其他样板的编辑结果，也不修改 3D 场景或正式世界存档。

### N5：行为真实性

时间、位置和活动信息具有明确来源。无法确认的状态保留未知含义；视觉过渡不被表述为经过模拟确认的行动过程。

### N6：性能与资源控制

样板运行不依赖现场生图或持续模型调用。平移、缩放和建筑移动应提供连续反馈，避免持续卡顿。验证记录实际设备、浏览器、帧率与操作表现；构建和浏览器测试遵守本机内存规则，与其他任务错峰调度。

### N7：恢复与反馈

数据读取、本地保存或恢复失败时，保留仍可用的状态，并提供明确反馈和恢复入口。重置本地编辑前须说明影响范围，避免误操作丢失布局。

### N8：验证证据

固定测试数据应能重复验证选择、遮挡、通路校验、撤销和刷新恢复；真实只读数据用于验证身份与地点绑定。截图辅助判断美术质量，功能通过须有实际操作证据。

## 不做的事

- 不实现 AI 世界生成、自然语言编辑或运行时生图；首期使用预先制作的庄园素材与布局。
- 不接入真实交谈、世界内身份控制或行动提交；用户以观察者身份体验。
- 不控制真实世界的暂停、时间推进或居民决策，也不因移动样板建筑而修改后端行动规则。
- 不实现正式场景存档、访客认领保存、跨设备同步或多人协作；编辑仅在当前浏览器保留。
- 不实现正式 2D/3D 双入口切换、跨视图几何同步或任意旧体素场景转换。
- 不实现分叉、比较、历史空间回放，以及各时间线独立的建筑版本管理。
- 不提供自由搭建、拆墙开洞、任意旋转、多楼层或独立道路绘制；首期编辑聚焦已有建筑的移动与撤销。
- 不扩展为完整室内编辑器；首期只提供一个可观察的室内空间。
- 不将任意活动文本转成动作，不以随机漫游代替真实居民行为。
- 不扩展多个主题、大规模居民、正式投票或公开发布；首期验证一个庄园样板。

## 验收标准

| 编号 | 对应需求 | 可观察的通过条件 |
|---|---|---|
| AC1：数据来源 | F1 | 分别打开真实只读数据和固定测试数据，界面正确标明来源；真实数据中的世界、时间线、居民与地点身份保持对应。 |
| AC2：刷新与失败恢复 | F2 | 手动刷新后，时间、居民地点和活动与返回的数据一致。模拟读取失败时，可看到失败提示与重试入口；保留的旧画面明确标记为尚未更新，重试成功后恢复正常。 |
| AC3：外景浏览 | F3 | 在固定视角下完成平移、缩放和返回全景，建筑、居民与入口仍可辨认和选择。 |
| AC4：选择与跟随 | F4 | 选择居民或地点后显示对应信息。跟随可呈现场景中的居民时，视图随其位置更新；取消跟随后可自由浏览。选中对象被遮挡时仍能辨认。目标位于样板无法呈现的地点时，保留真实地点信息并显示无法视觉定位的提示。 |
| AC5：室内观察 | F5 | 从指定入口打开室内，再返回外景，两者地点绑定正确。观察操作不改变真实世界中的身份或居民位置；建筑移动后仍能打开原室内。 |
| AC6：表现真实性 | F6 | 对照输入状态，居民地点和活动信息一致。缺少动作或移动过程证据时显示已知状态，不展示未经确认的行动。 |
| AC7：建筑移动 | F7 | 合法位置的预览可应用；越界、占地冲突或入口不连通的位置被阻止，并显示原因、保留原布局。应用后地点身份、室内绑定和居民归属保持一致。 |
| AC8：撤销 | F8 | 连续移动建筑后逐步撤销，布局与通路依次恢复；真实世界时间、居民状态和历史不被回退。 |
| AC9：本地恢复 | F9、N4、N7 | 编辑后刷新，恢复对应样板布局；不同数据来源、世界或时间线之间不混用布局。重置前说明影响范围，确认后恢复初始布局。本地数据损坏或不兼容时可获知问题并恢复。 |
| AC10：视觉质量 | N1、N2 | 检查固定昼夜场景：保持冷色悬疑风格，居民、道路、入口和编辑反馈清楚可辨；建筑移动后没有残留在原背景中的建筑图像或错位遮挡。 |
| AC11：桌面与触屏 | N3 | 在 1280×720 桌面和 390×844 手机竖屏完成浏览、选择、室内切换、建筑移动及撤销，主要控件可触达，操作不依赖悬停。 |
| AC12：隔离与运行证据 | F1、F6、N4–N8 | 检查样板发出的请求，确认不提交世界修改或调用模型。记录实际设备、浏览器、帧率及操作表现；连续操作无持续失去响应，失败可恢复，功能证据包含实际操作结果。 |

### 完整验收旅程

打开固定样板 → 选择并跟随居民 → 观察室内并返回 → 尝试非法建筑位置 → 应用合法移动 → 撤销 → 再次移动 → 刷新恢复 → 重置。

另用真实只读数据验证身份绑定、状态刷新与修改隔离。
