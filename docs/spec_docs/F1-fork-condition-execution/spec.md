# F1：受支持的分叉条件真实执行 Spec

> 状态：完整 Spec 已获用户批准；Plan 已启动。
> 日期：2026-10-04。
> 工作包：development_arrangement 中 B 线 F1「少量受支持的分叉条件真实执行」。

## 背景

当前世界分叉流程接受自然语言 what-if，预览模型生成场景草稿。用户确认后，系统只保存分叉设定并创建子时间线；“改变的条件”仍是描述文本，并不保证成为子线中的实际状态。系统已有独立的环境改变和消息传递动作，可产生带时间线版本、来源和事件的记录，但尚未与分叉创建原子结合。K1 已建立居民知识和时间线可见性规则，F1 将沿用这些规则。

## 目标

让用户在已有自然语言预览后确认一项明确、可验证的子线初始改变。首批支持向指定居民传递消息，或改变指定地点的天气、照明、通行状态之一。创建分叉与应用该改变全有或全无，源时间线不被修改。

## 功能需求

- **F1（入口与建议）：** 仅支持登录用户的自有世界分叉流程。用户输入自然语言 what-if 后，预览模型可在同一预览中建议一项结构化初始动作；模型不能执行动作。确认页展示并允许用户编辑动作类型及参数，只有用户明确确认后才提交。不支持的描述、缺失字段或无效参数不能创建分支。
- **F2（动作数量与环境范围）：** 每次分叉最多执行一项初始动作，动作类型为消息传递或环境状态改变。环境类别限天气、照明、通行，类别使用固定选项；目标值为非空自定义文本，最多 200 字。地点必须属于该世界。原有 `changedVariable` 描述本身不代表状态已执行。
- **F3（向居民传递消息）：** 用户指定该世界中的接收居民、主题和内容；主题最多 80 字，内容最多 500 字。确认页可从所选源时间线在分叉时刻可继承的合格证据中选择一条作为来源。无来源的消息记为传闻；有来源时沿用来源的事实或传闻级别。消息成为接收者的私人知识，公共事件不得暴露正文。
- **F4（地点环境改变）：** 环境动作在子线起点写成与地点和状态类别关联的世界可见事实及事件。居民只能依照 K1 的知识和时间线可见性规则获知。首版不承诺图形表现、导航或物理行为随记录改变。
- **F5（校验与原子提交）：** 服务端重新校验权限、源线、地点/居民、动作类别、字段长度和来源证据。源时间线须可写且活跃；带初始动作的 F1 路径允许世界模拟暂停，并将动作作为子线起点初始化。该暂停例外不改变不带初始动作的既有分叉门禁。分叉快照与初始动作的命令、事实和事件作为一个原子结果提交；动作记录在子线分叉起点。失败时不得留下部分子线、动作记录或源线改动。
- **F6（幂等和反馈）：** 相同请求 ID 和相同条件重试返回原分支与动作结果，不重复执行；同一 ID 用于不同条件时返回冲突。成功反馈明确说明已执行动作和子线；失败反馈说明原因并保留用户输入。

## 非功能需求

- **N1（显式确认）：** 模型输出只作为草稿；只有用户在确认页确认的结构化动作可以执行。服务端不得信任模型返回的参数而跳过校验。
- **N2（一致性）：** 子线和初始动作采用单一原子提交。源线或其分叉水位在预览后发生变化时，拒绝过期确认并要求刷新预览。父线和兄弟线不产生写入。
- **N3（隐私边界）：** 消息正文只进入指定接收者的私人知识。地点事实按 K1 规则进入可见上下文。来源选择限于目标分叉时刻可继承的合格证据。
- **N4（可追溯性）：** 每个已执行改变都能通过唯一操作标识定位提交结果，并保留其时间线版本、来源和派生事件。失败反馈不得包含模型密钥或提供方响应正文。
- **N5（预算与范围）：** 动作建议与场景草稿共用现有预览模型调用；确认应用动作时不增加模型调用。沿用既有预览预算护栏和字段长度限制，每个分叉最多一个初始动作。
- **N6（兼容）：** 已有旧分叉及不带初始动作的分叉流程仍可读取和使用。旧 `changedVariable` 不得显示为已执行改变。独立世界动作接口保持现有行为。

## 不做的事

- 首版不在访客/demo 分叉中执行初始动作。
- 不把地点状态连接到天气渲染、导航阻挡、碰撞或其他物理规则。
- 不执行任意自然语言、多个初始动作、顺序步骤、延迟触发或条件触发；不支持的动作须拒绝创建分支。
- 不推断消息真实性或绕过来源确定性；不处理电话、当面交谈和人物实际在场语义，后者属于 K2。
- 不实现 E1 的变化因果解释、完整证据浏览或离线回顾；本期只反馈本次动作提交结果和分支。

## 验收标准

- **AC1：** what-if 预览只建议动作、不创建分支或执行动作；确认页能展示和编辑动作参数。无法映射到支持动作的输入不可确认。
- **AC2：** 确认消息动作后，子线在分叉起点保存接收者私有知识与不含正文的公共事件；只有指定居民上下文含消息正文。无来源为传闻，合格来源的事实/传闻级别被保留；无效或不可继承来源被拒绝。
- **AC3：** 确认环境动作后，子线保存所选地点、天气/照明/通行类别和值对应的世界可见事实与事件；其居民证据可见，父线和兄弟线无对应记录。
- **AC4：** 不属于该世界的居民或地点、未知类别、空值、超限字段、不合格来源、越权请求或归档源线均失败，且不留下分支、命令、事实或事件。
- **AC5：** 源线可写且活跃时可创建；模拟暂停不阻止子线初始动作。成功时子线快照及初始动作结果原子持久化，命令、事实和事件的版本与模拟时间对应分叉起点；源线版本和内容不变。成功反馈与已持久化结果一致。
- **AC6：** 在原子提交写入点注入失败，不留下部分分支或动作记录，源线不变；若预览后源版本变化，确认返回冲突并要求重新预览。
- **AC7：** 相同请求 ID 和相同负载重试返回原结果且不重复应用；相同 ID 的不同负载返回冲突。
- **AC8：** 只有世界所有者能在满足现有写入和证据门禁的活跃源线上提交；不满足的请求失败关闭。
- **AC9：** 真实 fork UI 流程覆盖自然语言输入、结构化动作建议检查/编辑、明确确认、成功反馈及失败后保留输入；现有不带初始动作的普通分叉和 demo 分叉仍可用。
