# 持续生活版本

目标：进入世界的人能接着上一次交谈、收到可回看的口信、参与约定，并在回来时看到有依据的后果。分叉对照展示记录差异，不宣称推断出了真实因果。

本轮交付：

- 修复匿名演示、每次模型请求前的原子额度控制、流式全程超时。
- 连续现场对话：服务器保存历史、同线同地点恢复、请求幂等与并发保护。
- 持久收件箱：读取无副作用、显式确认已读、时间线隔离。
- 归来回顾：事件水位而非模糊名字匹配；明确确认看过；可打开来源。
- 约定：人物可提出赴约/帮忙，用户确认后生效；赴约、履约、失约和解释形成事件与人物记忆；到期处理不调用模型。
- 人物持续目标与约定进入其下一次决策上下文。拒绝邀请不等于违约；不替用户自动承诺。
- 分叉快照与对照：保存分叉时事实边界，展示两线人物状态与事件证据。

验收重点：真实数据库与路由测试，跨用户/跨线拒绝、重复请求、预算并发、断线、到期重复执行、刷新恢复。用模拟模型验收，不花真实 key 的费用。保持本地数据，不部署、不推送。

边界：这是可参与的叙事生活，不制作农场、战斗、背包或声称 AI 具有意识。旧分叉若缺快照必须标注不确定，不能捏造历史。
