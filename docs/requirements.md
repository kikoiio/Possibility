# Wispiva 需求基线

日期：2026-10-24
状态：已确认（需求访谈收口）

## 1. 产品定位

Wispiva 是第一用户（作者本人）的平行世界模拟器。核心乐趣是：模拟事件 → 观察结果 → 改条件 → 看世界变成什么样，像改写小说的平行世界。

成功标准是"好玩、满足幻想与好奇心"，不服务其他假设用户。

## 2. 世界与时间

- 世界持续运转，时间与真实时钟耦合（真实时间耦合模式）。
- 倍速按世界时间/真实时间定义：默认 24×，即 1 真实小时 = 24 世界小时（1 世界小时/2.5 真实分钟）；可加速、可随时暂停。
- 用户离开观看的平行世界继续运转；回来时可回查"离开期间发生了什么"的 log。

## 3. 一缕与织网（平行世界语义）

术语体系（与产品名 Wispiva 呼应：wisp = 一缕）：

- **一缕**：一个持续运转的世界；初始世界称**主缕**。
- **抽出一缕**：开辟平行世界的动作（内部实现可沿用 fork 概念）。
- **织网**：所有世界构成的整体；多世界同屏时，共享历史是同源丝线，分岔后各自延展成网。

- 任意时刻可抽出一缕。
- 用户可自由修改任何东西：角色、事件、世界设定皆可；支持一次批量修改多项。
- 用户确认修改后，抽出一缕修改后的世界继续运行；原世界不受影响。
- 所有缕持续运转，随时切换观看与对照。

## 4. 事件引擎

- 纯 LLM 驱动，不预设固定行为规则。
- prompt 携带角色现状（状态、关系、近因事件），由 LLM 决定角色行为。
- LLM 调用节拍与成本上限由用户自行配置。

### 待原型验证的假设

纯 LLM 非确定性引擎下，fork 对比是否依然"好玩"——差异来自用户的修改还是 LLM 随机性。若验证失败，回退方案是引入固定种子或混合模拟内核，需重新访谈确认。

## 5. 呈现

- 观看必须是实时的、有画面的。
- 2D 与 3D 两种渲染并行实现（先后顺序未定，均為确定需求）。
- 完整历史 log：随时回查任何一缕发生了什么。
- 多世界同屏展示的视觉隐喻是**织网**：世界如丝线并行延展，共享历史在同源处交汇，分岔处高亮。

## 6. 世界创建

- 带 LLM 的编辑器：用于创建和编辑世界与角色的初始设定。

## 7. 运行与部署

- 默认本机运行：进程不在则世界冻结。
- 架构支持自托管云服务器实现 7×24 常驻（用户自己配服务器，或付费由作者部署）。
- 云端常驻是可选部署形态，不是第一版必需。

## 8. 旧代码处置

- 旧实现全部冻结为参考素材，不迁移、不兼容、不约束新需求。
- 已于 2026-10-24 从 main 删除，可从 git 历史 `f0c207e` 查看。

## 9. 原型范围（按风险排序）

1. LLM 事件引擎 + 加速/暂停 + 任意时刻自由批量修改并抽出一缕 + 织网对照 + log —— 产品灵魂，先验证"好不好玩"。
2. 带 LLM 的世界/角色编辑器。
3. 2D 与 3D 实时画面。
