# 原型架构

核对日期：2026-10-29。本页描述当前工作树；产品目标见[项目意图](intent.md)，计划与历史验收证据见[工作计划](PLAN.md)。

## 入口与数据流

`server.mjs` 在本机提供网页、API 和 SSE；`ui/` 展示创建对话、3D 场景和已发生的世界动态。创建过程由 `world-creation.mjs` 管理，`creation-dialogue.mjs` 组织对话和建造意图，`world-genesis.mjs` 将模型生成的条目组装为世界起点。程序校验候选结果，用户确认后才进入世界。

`voxel-building.mjs`、`voxel-tools.mjs`、`voxel-world.mjs` 负责有限体素编辑、对象记录和撤销／重做；`voxel-bindings.mjs` 连接体素与世界语义。确认时保存当前体素快照，运行页使用该快照。`geometry/` 和 `ui/` 将世界状态编译并展示为场景。

`world-definition.mjs`、`core.mjs` 和 `actor.mjs` 管理规则、事实和角色观察；角色通过自身可见的观察选择行动，程序裁定结果。`activity.mjs` 将已提交变化投影为动态。作者界面是全知视图，角色输入受到信息边界约束。

`model/` 负责模型配置、请求和素材检索。素材保存在本机，创建对话按需提供检索片段，模型可请求一次补充检索；这不证明长文档理解可靠。

## 创建与反馈

界面明确选择“动手建造”或“先聊想法”。讨论不执行命令；建造结果由程序区分待执行、已提交、无变化、无建造指令、失败和取消。`creation.attempts` 将意图、重试关系、诊断、版本差异及耗时保存在一起；画布显示实际接受的版本。模型说明不是执行凭证。

`creation-attempt.mjs` 只整理无歧义格式：盒子角点排序、材料大小写和空白、`air`／字符串 `null` 转为空格。未知材料、含糊的屋顶高度等仍拒绝整批提交。重试由用户明确触发，复用原意图、读取最新场景，并检查客户端基准；刷新或重启不会自动请求模型。

已有保存的设定后，作者可主动查看草稿，无须等待模型的 `ready` 推荐；请求仍检查当前对话版本。起点生成按阶段保存结果。中断后可继续尚未完成的阶段，前提是对话和体素基准未变；最终规则检查失败时，按诊断撤回负责阶段及后续检查点，让下一次显式继续真正修复错误。最终草稿保存成功后才提供确认。

创建、预览与运行使用同一体素内容。“查看室内”仅隐藏屋顶显示，不修改存档。运行中的人物仅在地点精确匹配且有地面和净空时显示；尚无连续行走动画。

建造命令可用 `objectId` 记录实际写入的方块归属，存为对象的 `members`；`paint-object` 只改变这些方块。直接改块会使被覆盖的旧归属失效；方块、归属和历史一起提交、撤销与恢复。旧对象只有包围盒时不能安全推断归属，部件换色会拒绝并提示明确重建。归属在模型上下文中也无损合并为区间。

`geometry/voxel-inspection.js` 在候选结果提交前检查单层矩形建筑：`building.from.y` 是地板，检查两格净空、室内外相接门洞、墙顶开口、屋顶覆盖、窗户位置和水相交。检查结果随本次尝试保存，在画布下方显示并传给下一次模型。分步建造可以保存尚未完成的场景；这些有限诊断不是碰撞引擎、任意建筑可通行证明或外观合格结论。

模型调用记录连接响应、首段正文、生成、校验和提交等可实际观测的耗时；没有正文时首段正文时间为空。长等待可取消并保留意图。大场景发给模型时，将同材料的连续方块无损合并为区间，不省略门洞或对象。JSON 兼容仅整理可明确识别的冗余标点，记录调整；根对象重复字段、截断内容或含糊结构仍拒绝。

`WISPIVA_LLM_REASONING_EFFORT` 是可选的服务参数，留空沿用供应商默认；兼容性和输出质量需实测，不设通用推荐值。起点使用 NDJSON，不强制与之冲突的 JSON object 输出模式。

## 保存与边界

`.data/prototype/` 保存创建过程、世界状态、体素与归档。页面关闭后服务仍可推进；服务进程退出时世界冻结，重启不补算离线时间。完整历史仍驻留内存并整体写入文件，长期容量和断电耐久性尚未验证。

新建造将体素、撤销／重做历史及对话结果放入 `creation.json` 的 `voxelSnapshot`，通过同一次文件替换保存，成功后才更改内存。保存失败不显示已提交；提交阶段取消不能先保存乐观成功结果。创建文件无法读取、解析或版本不支持时停止启动，保留原文件供恢复。旧独立体素文件仍可读取迁移。运行状态与创建状态仍是分开的文件，不具备跨文件事务。

当前模拟覆盖地点连接、有限角色信息隔离、行动前提、资源和条件过程；它不是通用物理或完整小说模拟。长期相关性记忆、反思、分岔、连续寻路、复杂空间及大型世界尚未完成或验证。隐私检查只能拦截部分泄漏，不能证明自然语言推理完全安全。

## 检查

`node verify.mjs` 串行运行离线行为检查，使用合成模型，不读取私有模型配置、不调用真实模型，也不启动浏览器。`tests/` 包含定向测试，`scripts/` 包含手动和浏览器观察脚本；`.github/workflows/prototype-preview.yml` 定义云端浏览器验收。浏览器、真实模型和多模型效果需要分别验证，不能从离线测试推断。

本分支只维护主原型；Luanti 社会实验位于独立分支，不是原型运行依赖。
