# 主体记忆研究

记忆研究为持续角色提供检索、反思与叙事身份的参考。这里讨论的是角色如何保留自己的经历、如何从过去提取信息，以及检索结果如何受情绪与关系影响。它不把记忆表、摘要或检索分数当作记忆可信度的证明。

产品目标与约束见[需求](../intent.md)；Wispiva 的记忆表示、写入、检索和反思方案见[架构 §4](../design/2026-10-27-target-architecture.md#4-主观记忆)。

## 研究来源

| 来源 | 研究方向 | 阅读与证据边界 |
| --- | --- | --- |
| Generative Agents（Park et al., 2023） | 持续记忆流、最近性／重要度／相关性检索，以及 reflection。可供研究事件显著性和反思如何影响后续角色行为。 | 现有资料没有逐项记录完整论文阅读深度或源码核查；最近性、重要度、相关性三因素的效果未在 Wispiva 复现。不能据此断言某种权重组合对长期角色记忆最优。 |
| HippoRAG / HippoRAG 2 | 以知识图和 Personalized PageRank（PPR）式激活传播支持实体关联与多跳联想检索，适合研究由人物、地点或关系找回间接相关经历的路线。 | 现有资料仅保留方法线索，没有实现核查或 Wispiva 效果实验。本地以实体图做两跳检索只是相近的结构选择，不等于复现 HippoRAG 的算法或效果。 |
| [Emotional RAG](https://arxiv.org/abs/2410.23041) | 研究角色扮演情境中的情绪一致性检索，可作为情绪如何影响回忆排序的参考。 | 现有记录没有逐项确认全文阅读深度，也没有本地复现。不能从该方向推出长期世界模拟、分岔后偏见变化或情绪记忆准确性已经得到验证。 |
| [McAdams：叙事身份](https://journals.sagepub.com/doi/abs/10.1177/0963721413475622) | 以叙事身份理解当下自我如何重新讲述过去，可帮助区分发生过的经验与角色如今如何解释它。 | 现有记录未核实全文阅读或实证研究范围。它提供概念参照，不是记忆编码、叙事更新或模拟规律的实证验证。 |
| MemGPT / Letta | 分层记忆与上下文管理的框架方向。 | 现有资料没有记录版本、代码路径、运行效果或兼容性核查；不构成引入依赖的建议。 |
| Mem0 | 面向 agent 的记忆管理框架方向，可供检索与记忆更新方案比较。 | 现有资料没有记录版本、实现审计、效果复现或成本测量。 |
| Zep | 对话记忆、时序组织与检索的框架方向。 | 现有资料没有记录版本、实现审计、效果复现或与 Wispiva 的兼容性。 |

这些来源覆盖的任务与证据类型不同：角色模拟、关联检索、情绪排序、身份叙事和工程框架不能互相代替。引用研究时应明确资料支持的是概念、算法、公开实现还是在特定测试中的效果。

## 需要分别表达的记忆问题

角色的记忆至少涉及三种不同对象：

- **客观记录**：世界中发生过什么、提交了哪些变化，以及对白的原文。
- **原始主观体验**：某个角色实际观察、理解并感受到什么。
- **如今讲法**：角色从自己的经验重新组织出来的反思、解释与自我叙事。

把三者压成一个“记忆文本”会混淆历史事实、观察范围和事后解释。对白原文与角色的主观要点也承担不同用途：前者可供历史回查，后者体现该角色如何经历事件。每个角色拥有自己的经验；多人对同一事件的记忆可以不同，且需要有来源关联。

## 研究线索与设计检验

现有文献线索提示可以分别研究：

- **编码**：事件对这个角色意味着什么；情绪极性、强度、重要性和相关对象如何记录，评价理由能否帮助发现错误标注。
- **检索**：时间衰减、事件相关性、实体关联、关系极性和情绪是否影响回忆顺序；情绪增强显著性是否会牺牲准确度。
- **反思**：被问及过去、旧记忆闯入当前情境、叙事冲突或独处等情境，是否能触发有用的反思；普通线索是否只需检索而无需每次生成新反思。
- **归属与知情边界**：检索结果是否只属于记忆拥有者；角色是否会从其他人的经历、隐藏事实或未来预测中得到未曾观察的信息。
- **重述与更新**：当角色改变解释时，能否保留原始经历并更新现在的讲法，而不反复摘要旧摘要、累积漂移。
- **分岔与成本**：多个世界线的记忆如何从共同经历分开；检索量、上下文长度、模型调用次数、延迟与预算怎样共同影响长期运行。

可用于验证的案例包括：多位角色经历同一事件后形成不同而可追溯的经验；角色对中性事件与强烈事件的回忆行为不同；偏见能影响检索却不改写客观记录；只有获得信息的角色会知情；对话逐字历史与每位角色的主观记忆彼此对应；分岔后共同经历可继承，之后的经历不串线。

这些项目是评价问题，不是论文已证明的普遍规律。情绪强度不等于记忆准确度；按 owner 检索不能单独阻止其他 prompt 输入泄漏；记忆聚合可能遮蔽单条错误标注。写入数据库、能够检索到文本或分数合法，都不足以证明主体记忆质量。

## 证据范围

现有记忆资料没有记录每篇论文和框架的完整阅读深度，也没有本项目对检索算法、反思质量、长期偏差、跨线隔离或调用成本的对照结果。HippoRAG 两跳关联、FTS5 trigram 命中、关系极性加权、embedding、agentic 检索、原始经验再固化和认知失调检测等均应分别核对来源与实测效果；不能因概念相似便宣称复现某篇研究。

研究结论应以具体实验的主体数量、事件类型、时间跨度、信息可见范围、模型、提示、成本和失败案例为边界。展示一个角色讲述连贯，只说明该样例可生成，不能说明记忆准确、来源可追查或长期不会漂移。

## 部分可观测性与本轮原型证据

近期的 [Belief-State Engine](https://arxiv.org/abs/2609.10036) 和 [Belief-Based World Models](https://arxiv.org/abs/2609.00455) 将部分可观测环境中的已知、未知与信念作为可查询的外部状态。它们提供的可迁移问题定义是：LLM 根据历史生成下一步，不等于系统已经维护了可审查的主体信念。本文只核对摘要，未复现实验；这里不把它们的结果当作 Wispiva 已验证的实现方案。

本轮原型的实现证据更窄：角色输入只包含经过观察投影的世界、本人起源记忆和本人经历；事实用 `knownBy`，线索用 `discoveredBy`，对白用当时的 `listeners`，秘密资源和行动用角色／线索可见性过滤。红发会夹具验证了“知道、当前看见、可执行、主观记忆”必须分开。一次真实创建世界还显示，模型可能把私有计划写进公开地点描述或 premise；因此结构校验通过不代表主体信息边界正确，观察投影也必须把 author-facing prose 当作潜在泄漏面处理。

后续原型把这类失败接入创建世界接受前的隐私审计：它能对角色投影做确定性越权检查，并对公开文字与私有目标／隐藏机制做有限片段重合检查。这个审计只保护当前起点的输入边界，不能替代长期记忆的来源追踪，也不能判断同义改写、暗示和角色在后续对话中的推理是否越权。

当前结果仍只是短期、有来源的经历账本：没有验证长期信念更新、概率化未知、错误线索的持续影响、反思、分岔后信念继承或不同检索策略的准确性。后续实验应记录同一客观 revision 下不同角色的观察、已知集合、行动权限和经历行，并比较保存恢复、线索发现和跨线分支后的可追溯性。
